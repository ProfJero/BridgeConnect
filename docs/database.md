## Conventions

- **Primary keys:** `uuid` (`gen_random_uuid()`); `audit_logs`/history tables use identity bigints.
- **Enums** for closed vocabularies (statuses, types, roles); **CHECK** constraints for formats and lengths.
- **Polymorphic targets** (favourites, reports) use one nullable FK per target type plus
  `CHECK (num_nonnulls(...) = 1)` so referential integrity holds.
- **Slugs** are generated by triggers (`private.unique_slug`); `slug` columns default to `''` only so generated
  types treat them as optional.
- **Search:** generated `tsvector` columns with GIN indexes; trigram indexes on names.
- **Indexes** on every foreign key used for filtering and on the main list orderings (feeds, queues).
- **Timestamps:** `created_at`/`updated_at` (`private.set_updated_at` trigger).

## RLS conventions

Every table in `public` has RLS enabled and:

1. `revoke all` is the default (migration 0001 alters default privileges);
2. explicit `grant select` and **column-level** `grant insert (…)`/`grant update (…)` to `anon`/`authenticated`
   only where needed — e.g. users may update `profiles.display_name` but not `account_status`;
3. policies per action, named in plain English;
4. helper functions are `STABLE SECURITY DEFINER` with `set search_path = ''`, read only `auth.uid()` and live in
   `private`.

Sensitive state machines are **only** reachable through RPCs (no client write grants): role assignments, order
status, application decisions, moderation, ad review, alert issuing, notifications, audit logs.

## Seed data (`supabase/seed.sql`)

Development only, applied by `supabase db reset`:
- Central Region → Abura-Asebu-Kwamankese District (Kwamankese, Abakrampa, Asebu) and Cape Coast Metropolitan
  (Cape Coast) for cross-area testing;
- eight demo accounts (`is_demo = true`, `.test` emails, shared dev password) with scoped roles;
- four verified demo entities, listings, posts, a pending application, emergency contacts and an advisory.

Purge before launch with `supabase/scripts/remove_demo_data.sql`.

## Regenerating types

```bash
npm run db:reset   # local
npm run db:types   # writes src/types/database.ts
```
